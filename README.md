# Study Data Analysis

Projeto de análise exploratória de uma pequena base de dados sobre hábitos de estudo.

## Perguntas analisadas

- Quantas horas de estudo aparecem em média?
- Existe relação entre horas de estudo e nota?
- Como as horas de sono variam entre os registros?
- Qual a distribuição das notas?

## Tecnologias

- Python 3
- Pandas
- Matplotlib
- CSV

## Como executar

```bash
pip install -r requirements.txt
python analysis.py
```

O projeto foi criado para praticar leitura e organização de dados, estatística descritiva e visualização.
